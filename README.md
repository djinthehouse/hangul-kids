# 한글 놀이터

유아·초등 저학년을 위한 한글 놀이 웹앱 (단일 HTML · PWA).

- 따라 쓰기: 자음·모음·글자의 획순을 손가락으로 따라 쓰고, 시작점·방향·순서를 확인합니다
- 글자 만들기: 자음 + 모음 (+ 받침)을 골라 들리는 글자를 만듭니다
- 그림 낱말 · 듣기 · 짧은 문장 · 이야기 5편 · 말하기(마이크)
- 하트·리그 없음 — 틀린 문제는 조금 뒤에 다시 나옵니다. 칭찬 도장과 칭찬 스티커
- 부모님 화면(계산 문제로 잠금): 놀이 시간, 단원별 진도, 자주 헷갈리는 글자, 하루 놀이 시간 제한

English Camp · Macao Lee · にほんご道場 과 같은 엔진을 씁니다. 기록은 기기에 저장되며, 로그인하면 Firebase(`progress_ko`)로 이어집니다.
